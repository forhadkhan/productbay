Phasing How the backlog turns into releases

Candidates are the bank; each phase pulls from it. Phases 0–2 fix credibility & build the moat; 3 wins B2B; 4 owns merchandising; 5 scales.

Phase 0 · 2–4 wks

Prove the promise

  • Caching (free)
  • Fix price-filter wiring
  • Cache-bust + PHPUnit/CI
  • Pro 1.0.2 responsive fix
Phase 1 · Q1

Table stakes

  • Sort headers, sticky header/col
  • Attribute filters, basic price filter → free
  • Data CSV export, total-cost column
  • Quick View + gallery (pro)
Phase 2 · Q2

Modern & fast (moat)

  • Interactivity API
  • Cart/Checkout Blocks + Store API
  • Large-catalog indexing
  • HPOS audit
Phase 3 · Q3

Win B2B / wholesale

  • Role pricing, tiered discounts
  • Quote mode, hide-price, MOQ
  • CSV bulk quick-order upload
  • Role-conditional display, PO field
Phase 4 · Q4

Own merchandising

  • Archive override
  • Wishlist/Compare/order-history columns
  • Conversion analytics
  • AI setup, template library
Phase 5 · Yr 2+

Agency & scale

  • Multisite/white-label licensing
  • Headless REST
  • Webhooks/automation
  • Enterprise SLA
Deliberately excluded (rejected from the competitor set): external/non-Woo data sources (Google Sheets, CSV/JSON/REST — Ninja, TableKit), general-purpose table building, niche columns (audio, charts, Amazon-affiliate tables), and a sprawling 50+ third-party integration surface. Staying WooCommerce-focused is the strategy, not a limitation.
